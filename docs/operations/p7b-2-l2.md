## P7B-2-D1：required Research tool omitted before model

Frozen L2-1 原指令：

> 请基于选中资料创建一张研究分析卡：两份材料对折叠接缝是否更易清洁意见冲突。保留冲突和来源，把它转成影响结构、排水与清洁路径的设计取舍及可执行验证。台面尺寸未测、承重未验证，不要编造数值或将候选自动保留为关键结论。

生产 Runner 的 contract 为 `chatAnalysis / discussion`，唯一 activity 为 `historyAndMemory`，
没有 `create_research_analysis` grant。原始 userGoal 未修改，但 activity instruction 变成
“请基于选中 。保留冲突和来源……”。生产 Server 最终 body 的六个 tools 是
`read_selected_context / read_project_memory / read_stage_record / search_project_conversation /
submit_memory_update / read_workspace_source`，所需 Research candidate tool 不存在。

已验证直接原因：`stripUntrustedInstructionSegments()` 的 `REFERENCE_FRAME` 匹配
“资料创建一张研究分析卡：两份材料……冲突”，误把本轮用户 action 当成引用 frame 删除。
`createResearchAnalysis` positive rule 另外要求 action verb 后直接出现研究/调研/分析，
不接受“一张”。`resolveTurnTaskContract()` 未产生对应 grant；Server 忠实按 client-owned
contract 过滤 tools，不能由模型自行补权。

归因是 deterministic user instruction / authority routing，发生在 model 之前。
额外 `submit_memory_update` exposure 是观测事实；本轮没有实际 tool execution，
不据此断言 unauthorized state mutation。D1 的确认依据是 required Research tool omission。
没有为了绕过问题删除量词、改变冒号、选择额外 UI mode 或修改 fixture/prompt。
产品、SQL、schema、migration、原 frozen contract/oracle 均未改。
