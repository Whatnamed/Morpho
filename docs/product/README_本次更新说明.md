# Morpho v3.1：原型前规则更新说明

这套文件是在现有 v3 基线之上做的产品规则更新，用于进入 UI / 交互原型前的统一依据。

## 本次正式写入的变化

1. **选中对象后的可编辑建议**：系统按对象类型、数量与直接关系给出少量建议；点击仅填入聊天输入框，不自动发送、执行或切换当前工作重点。
2. **确定性下一步建议**：研究分析、关键结论、设计定义、方向、交付结构等成果出现时，系统准备可选下一步；在用户下一次继续聊天时轻量呈现，不依赖模型持续监控，也不判定“阶段完成”。
3. **连续视觉发展**：预览、主图、场景、CMF、角度、细节与示意从“阶段门槛”改为图像角色与生成意图；任意选中的图都可以继续发展或衍生表达。
4. **后续默认参考**：用户可将某张图设为后续相关生成的默认一致性基线（系统内部仍叫主视觉锚点），但它不是生成其他图的前提。
5. **交付准备边界**：Morpho 当前整理交付结构、文字、素材、图注、缺口与可选视觉参考图；最终展板 / PPT 精细排版留给 Figma 等外部工具。
6. **恢复与失败体验**：项目重开维持退出时视图状态；失败、取消和不可读资料原地提示，并保留重试和替代路径。

## 本次没有进入的内容

- 开发架构、数据库、状态机、接口与模型路由；
- 起始阶段“自动读取刚导入的一批资料”的增强能力；
- 最终 PPTX、HTML PPT、自动展板排版、Figma 级编辑；
- 更复杂协作、外部网页调研、资产治理和跨项目检索。
