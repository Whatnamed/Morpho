The image object — the visual anchor of every Morpho canvas.

\`\`\`jsx
<ImageObject role="主视觉" title="柔光轨道 v2" width={320} height={214}><ProductVisual variant="rail" /></ImageObject>
<ImageObject role="细节研究" title="转角连接件" width={240} height={158} src="…" />
\`\`\`

Square corners on the frame, \`object-fit: contain\` so nothing is cropped, and the caption floats **outside** the image on the canvas ground. Never wrap an image in a rounded white card with an info block — that is the old treatment.
