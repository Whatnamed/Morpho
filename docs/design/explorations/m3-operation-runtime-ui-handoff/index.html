夜间起身路径与扶持需求调研

独居老人夜间起身主要依赖记忆路径，单点扶手无法覆盖转身与门框过渡。

主要发现

连续低位引导比单点扶手更符合真实起身动作路径。

设计定义
让独居老人从床边到卫浴的最后几米更容易辨认、扶持与转身。

核心问题：夜间起身路径缺乏连续支持，现有扶手医疗器械感过强。

低施工、可适配租住与老房场景
连续支撑，而非单点扶手
低干扰照明，居家语气
概念方向 A

柔光轨道

将低位柔光、可触摸导向与隐蔽支撑融入墙面，形成连续辅助路径。
